# ai-project-scanner

## Tentang Project

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules. Currently, two official plugins are available: - @vitejs/plugin-react uses Babel (or oxc when used in rolldown-vite) for Fast Refresh - @vitejs/plugin-react-swc uses SWC for Fast Refresh

## Tech Stack

Node.js; deps: @ai-sdk/google, ai, clsx, framer-motion, lucide-react, react, react-dom, tailwind-merge; dev: @eslint/js, @types/node, @types/react, @types/react-dom, @vitejs/plugin-react
